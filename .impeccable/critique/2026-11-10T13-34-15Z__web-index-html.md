# AI Remix Relay 产品与界面审查

## 结论

产品不是只有 API 缺口。视觉语言和“接下一棒”的概念成立，但当前总体为 22/40（可接受，仍需显著完善）。最大问题是多人接力、创作者权益、可增长谱系和付费闭环尚未成为真实产品能力。

## 优先问题

### P1：谱系无法正确持续增长

分支由 `parent_id !== n2` 推断，而不是由图拓扑计算；第六个以后节点复用同一位置并重叠。Relay Graph 是产品核心，但当前超过五个节点就无法可靠表达。

### P1：多人和留存外壳大多不可用

“发起 Seed”、收件箱、“我的创作”和两个 Feed 条目只显示延期 Toast。链接能打开节点，但没有邀请记录、接收状态、通知、定向交接和回访触发器。第二位创作者如何进来、第一位创作者为何回来都没有产品闭环。

### P1：授权、署名和收益记录不完整

数据模型缺少 license、split 和 rule result。页面显示的 Content hash 实际是元数据回执哈希，抽屉仍写 Guest creator。用户无法确认自己授权了什么、作品是否满足规则、以后如何获得收益。

### P1：商业模式只有介绍，没有可测试能力

页面承诺免费次数、Credits、Creator Plan、付费 Seed、商业授权和分成，但没有额度余额、价格、权益、扣费、退款、结算或收入账本。

### P2：首次使用和移动端连续性不足

邀请链接没有说明邀请者和上一棒变化。移动端隐藏收件箱与我的创作，900px 谱系画布没有滚动提示。生成中无法取消，失败仅用短暂 Toast，刷新会丢失未发布状态。

### P2：状态与可信度文案冲突

页面无条件宣称真实 AI 和公共存储，但缺 API 时实际不可用；证据区仍残留“本机浏览器”文字。公开发布没有授权确认、撤销或草稿机制。

### P2：可访问性缺陷

移动端品牌失去可访问名称；Feed、轨道和图谱的选中状态没有 `aria-current`/`aria-pressed`；生成和发布状态不是 live region；候选图以 CSS 背景呈现而无视觉差异说明；部分小字对比度不足，关闭按钮低于 44px。

## 技术检查

机械检测降级为正则模式，共发现 63 项设计系统漂移提示，主要是颜色、字号和圆角未完全落到 DESIGN.md token。桌面与 390×844 移动布局没有页面级横向溢出，X Layer RPC 读取成功，服务端失败能诚实降级。核心风险仍是五节点后图谱重叠和异步状态不可访问。

## 强项

- 丝网校样台的视觉方向具有产品专属性。
- “接下一棒”比普通 AI 生成器更容易理解和讲述。
- 生成、选择、发布、分享的基础路径已经具备真实服务化基础。

## 核心判断

API 只是让第一棒能生成；真正决定产品是否成立的是：第二个人怎样被邀请并完成下一棒，以及第一位创作者怎样收到结果、获得认可或收益并再次回来。
